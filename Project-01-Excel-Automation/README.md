# 📊 Project 01 - Excel Sales Automation using Python

## Overview

This project demonstrates an end-to-end data analytics workflow using Python, from data cleaning to automated Excel report generation.

## Dataset

- Sample Superstore
- 9,994 Rows
- 13 Columns

## Tools

- Python
- Pandas
- Matplotlib
- OpenPyXL
- Google Colab

## Workflow

```
Import Libraries
↓
Load Dataset
↓
Data Overview
↓
Data Quality Check
↓
Data Cleaning
↓
Exploratory Data Analysis (EDA)
↓
Data Visualization
↓
Excel Automation
↓
Business Report
```

## Business Questions

- How many records are available?
- Are there missing values or duplicate records?
- Which region has the highest sales?
- Which category generates the highest profit?
- How does discount affect profitability?

## Project Outputs

- Cleaned Dataset
- Automated Excel Report
- Business Visualizations
- Business Insights
